# VANTAGE Training Console v1.4.0

Local-first PWA for training, readiness, nutrition, recovery and health analytics.

## v1.4.0 platform foundation

- Flexible phases/training blocks with ±1 week extension
- Configurable programs/splits and rotation progress
- Full Body, Upper/Lower, PPL, body-part and Heavy Duty A/B starting presets
- Custom Routine Builder
- 461 built-in exercises plus custom exercises
- Profile-level optional module toggles
- Existing VANTAGE split migration
- Historical Markdown Import retained
- v1.3.10.5 canonical history/metrics matching retained

Open through the established local origin:

`http://localhost:8080/?v=140`

Do not clear browser site data when updating an existing installation.
